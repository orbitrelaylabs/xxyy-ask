# XXYY 当前支持的产品功能总览

本页是现有 XXYY 官方文档的功能目录，只汇总当前文档已经明确说明的产品能力。具体配置、限制和适用范围以链接的功能页面为准。

标准客服回答：XXYY 当前功能主要包括：1. Swap、挂单、自动交易和交易设置；2. 发现、行情、K 线和代币数据分析；3. Dashboard、持仓、收益、Holder 和订单管理；4. 钱包管理、钱包监控、Telegram 通知和扫链；5. Basic/Pro 权益与移动端登录。具体限制和操作步骤可以继续按功能名称查询。
