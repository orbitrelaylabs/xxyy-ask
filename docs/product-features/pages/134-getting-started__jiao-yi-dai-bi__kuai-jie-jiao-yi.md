# 快捷交易

### 快捷交易

xxyy 支持快捷交易面板，方便一键快速买入或卖出。点击右侧悬浮按钮，面板可悬浮在页面上自由移动。

默认快捷交易按钮

面板默认显示 4 个买入金额按钮和 4 个卖出比例按钮。

可在交易设置中自行修改买入卖出值

<img src="/assets/xxyy-docs-U1gKvw448ob3NrJZv2WV.png" alt="" height="265" width="345">

展开更多快捷按钮

拉大快捷交易面板，可展开至 8 个买入按钮和 8 个卖出按钮，满足更多交易需求。

<img src="/assets/xxyy-docs-EAITEoB9KFYg72vEkyjC.png" alt="" height="198" width="351">

<br>

交易设置（快捷交易面板右上角点击进入交易设置）

自定义买入卖出快捷按钮默认值

价格风险弹窗提示：池子流动性不足导致预估交易价格波动超10%时弹窗提醒

开启大额买入二次确认：可设置触发金额（如 ≥10 SOL）

<br>

### 交易类型

* 市价交易：按当前市场价格立即成交，下方可选 P1/P2/P3 预设配置

支持三套独立交易配置预设，每套可分别交易模式（Degen / 极速 / 防夹 ），防夹可以选择级别（基础/进阶/强化），调整滑点百分比及优先费（SOL），设置后快捷交易直接生效，适应不同交易场景。

* 限价交易：设置指定价格等待成交
* 狙击/自动卖：用于抢开盘或自动卖出
