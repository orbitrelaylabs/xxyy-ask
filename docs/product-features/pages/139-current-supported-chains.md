# XXYY 当前支持的公链

标准客服回答：如果问题是“XXYY 整体产品目前支持哪些链”，现有官方资料明确覆盖 Solana、BSC、Ethereum、Base、Robinhood Chain 和 Stable Chain，共 6 条链。不同功能的链覆盖范围可能不同，例如跟单、API Feed、钱包监控或某个发射平台不一定同时覆盖全部 6 条链；询问具体功能时应按该功能文档回答。

证据范围：

- [发现页面官方文档](https://docs.xxyy.io/getting-started/fa-xian)明确列出 Solana、BSC、ETH、Base 和 Robinhood。
- [官方 X 更新](https://x.com/useXXYYio/status/2080647020461854747)于 2026-07-24 宣布 Stable Chain 已全面支持交易、跟单、挂单和多钱包交易。
