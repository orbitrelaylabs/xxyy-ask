# XXYY 当前支持的发射平台

标准客服回答：XXYY 支持按链筛选发射平台：Solana 包括 Pump、LetsBonk、Believe、Raydium Launchlab、Moonit、Meteora DBC、Boop、Time、Bags、Jup Studio；BSC 包括 Four.meme；Ethereum 包括 Klik、Livo、Stroid、Trench；Robinhood Chain 包括 Noxa、Virtuals、Bankr、Varo。名单会随官方更新变化。

按链整理如下：

- Solana：Pump、LetsBonk、Believe、Raydium Launchlab、Moonit、Meteora DBC、Boop、Time、Bags、Jup Studio 等主流平台。
- BSC：Four.meme。
- Ethereum：Klik、Livo、Stroid、Trench 等。
- Robinhood Chain：Noxa、Virtuals、Bankr，以及最新加入的 Varo。

发射平台列表会随链和产品更新变化，这是一份当前官方资料明确点名的平台汇总，不应表述成永远不变的穷举列表。用户指定某条链时，应只回答该链有证据的平台；Base、Stable 或其他链如果当前证据没有完整列表，应明确说明资料未给出完整名单。

证据范围：

- [官网功能更新](https://docs.xxyy.io/changelog)列出 Solana 主流平台和 BSC Four.meme。
- [Ethereum 官方更新](https://x.com/useXXYYio/status/2053065378121839026)列出 Klik、Livo、Stroid、Trench。
- [Robinhood Chain 官方更新](https://x.com/useXXYYio/status/2075891974192947704)列出 Noxa、Virtuals、Bankr。
- [Varo 官方更新](https://x.com/useXXYYio/status/2082373707587273118)说明 Varo 已支持内盘、外盘交易和扫链。
