# 发现

位于XXYY界面左侧，可快速查看链上数据与动态。

链与布局

* 左上角切换链：支持 Solana / BSC / ETH / Base / Robinhood 六大公链
* 右上角切换布局：自带四种布局扫链模式 / 监控模式 / 热点模式 / 打新模式
* 可自定义布局：最多三列六栏
* 支持隐藏侧边栏

<img src="/assets/xxyy-docs-e67oLPCOc07Wvndi77sz.png" alt="" height="348" width="602">

布局操作

* 每一列有上下两栏，拖动中间分割条，调整两栏占比，下方栏右上角可快捷缩放/展开该栏数据
* 每栏最多可添加 4 种数据源，点击每栏右上角➕号调整数据源

<br>

可用数据源\
热门 / 收藏 / 趋势 / 币安Alpha / Bags认领 / Pump认领 / Dex趋势 / Dexs-AD / KOL买入 / Tagholder买入 / 新币 / 扫链新币 / 即将打满 / 已经发射 / Pump直播 / 钱包监控 / 推特监控 / 资产 / 活跃持仓 / 最近浏览

<img src="/assets/xxyy-docs-2nrnSqSocTQDhDMV2cB2.png" alt="" height="796" width="600">

交互\
点击代币可快速跳转到该代币交易界面。
