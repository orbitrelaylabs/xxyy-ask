# 收藏

发现优质项目，一键收藏，方便持续跟踪。

<img src="/assets/xxyy-docs-GtWZ8IVTBzwDsItjXGBO.png" alt="" height="662" width="296">

<br>

如何收藏\
在代币信息页，点击代币信息旁的 ⭐ 五角星图标，即可将项目加入收藏同时创建分组。

分组管理\
收藏时可选择或创建分组，将同赛道的项目归集到一起，方便聚焦特定板块，收藏板块右上角的设置支持增加、删除、编辑分组。

代币备注\
点击代币信息右侧的箭头图标，可为代币添加备注，方便标记个人关注点（如“这个项目有升级预期”）。

置顶与排序

* 点击代币信息最右侧的 📌 图标，可将重要代币置顶，优先关注
* 拖动代币信息最右侧的六个点（⋮⋮），可自定义代币展示顺序，按个人习惯排列

适用场景

* 观察板块异动
* 跟踪潜力项目动态
* 快速筛选赛道的在跑项目

查看与交互\
收藏列表支持按分组筛选，点击项目可快速打开交易界面。
