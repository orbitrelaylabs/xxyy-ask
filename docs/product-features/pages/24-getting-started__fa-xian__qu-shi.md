# 趋势

xxyy 独家算法驱动，多维度数据交叉分析——交易量、价格波动、流动性变化、聪明钱流向、持有人结构、社交媒体热度，实时计算，快速发现热门和潜力项目。

时间维度

* 1M / 5M / 1H / 6H / 24H

排序\
支持按价格涨幅高低排序，快速筛选最强表现项目。

协议筛选\
每条链都支持按协议筛选，不同链展示对应可用协议选项。<br>

项目展示\
列表展示代币名称、市值、价格、涨幅，时间表示池子创建时间，OG 标识方便识别。

点击任意代币可快速打开交易界面。
