# XXYY Agent 目标产品设计

## 产品目标

XXYY Agent 面向 Web、Telegram、HTTP API 和其他 Agent，提供两类证据受控能力：

1. 基于正式知识库回答 XXYY 产品功能、配置、权益和官方更新。
2. 对用户明确给出的公开交易，查询基础事实并进行 XXYY 成交、池子和结构性 Sandwich 诊断。

## 核心原则

- 证据优先：重要结论附来源；证据不足明确降级。
- 默认拒绝：Skill 只有被显式注册和授权后才能进入 Planner。
- 单一接入：外部使用者只安装需要的交易 Skill，不需要同时部署配套协议服务。
- 浏览器只读：公开交易路径只访问固定 Explorer 与 XXYY 页面，不调用 RPC。
- 用户可见截图：精确定位目标成交时返回真实整页 XXYY 截图，目标行居中并标注。
- 领域逻辑与入口解耦：Product RAG、浏览器采集、诊断 core 和 Agent 编排保持独立可测试。

## 功能需求

### 产品支持

- 支持中英文问答、引用、流式输出和证据不足回复。
- 知识来源只包括正式产品文档、官方社交更新和通过治理门禁的客服知识。
- 当前 Agent 在进程内直接调用 Product RAG，不维护独立的对外 Product Support Skill。

### 基础交易查询

- 接受支持的 Explorer URL、交易哈希或 Solana signature。
- 返回链、状态、区块/slot、时间、发送方、接收方、value、fee 和可提取的 token transfer。
- 页面信息不完整时保留原始证据范围，不推断 call trace 或钱包全貌。

### XXYY 交易诊断

- 从交易事实整理方向、金额、gas/fee、池子、交易者和币种。
- 在 XXYY 最新成交中按完整交易标识、时间和 maker 交叉定位目标行。
- 返回目标成交及前后成交的方向、地址、交易标识、数量、金额和区块等可取得字段。
- 仅在前后成交结构满足规则时给出结构性 Sandwich 判断；字段不足时返回数据不足。
- 区分“是否 canonical”和“是否小池子”，不能把最大池自动当作正确池。
- 返回真实 XXYY 整页标注截图，目标交易位于可视成交区域中部。

## 安全与边界

- 不查私有账户、订单、余额、地址历史或地址真实身份。
- 不执行签名、交易、授权或资金操作。
- 不提供投资建议、收益承诺或确定性损失估算。
- 网页内容按不可信数据处理，不能覆盖系统策略。
- API key、数据库密码和浏览器 profile 不进入回答、日志或截图。

## 成功标准

- 交易接入方只需一个 Skill 和本地浏览器，不需部署第二套服务；产品问答由当前 Agent 内部提供。
- 相同已验证输入产生稳定结构化输出。
- 页面变更、阻断和冲突安全降级，不生成伪造数据或伪造网站截图。
- `pnpm check` 覆盖 build、format、typecheck、tests 和 deterministic QA。
